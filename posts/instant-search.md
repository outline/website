---
title: Instant search
date: 2026-07-29T00:00:00Z
slug: instant-search
---

Search in the command bar is now instant. Rather than waiting on a round-trip to the server for every keystroke, results are matched locally first against a fuzzy, typo-tolerant index built right in your browser — so the list updates the moment you start typing.

Server results still arrive moments later and merge seamlessly into what's already on screen, giving you the best of both: the speed of local search with the completeness of a full workspace index behind it.
